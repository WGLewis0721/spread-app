# Spread: instructions for Gemini

This repository keeps all design guidance in one place: **[docs/design/README.md](docs/design/README.md)**.

Before you plan, spec, design or review any UI for Spread:

1. Read [docs/design/README.md](docs/design/README.md) and use its task router to find the governing documents.
2. Follow [docs/design/PLAN_SPEC_PROTOCOL.md](docs/design/PLAN_SPEC_PROTOCOL.md) and write specs with [docs/design/specs/TEMPLATE.md](docs/design/specs/TEMPLATE.md).
3. Read [AGENTS.project.md](AGENTS.project.md) for the project rules. Do not add colors, fonts or decorative styles; list anything that seems to need one as an exception for the owner to decide.

Do not put design rules in this file. Setup notes for each AI tool: [docs/design/AI_TOOL_SETUP.md](docs/design/AI_TOOL_SETUP.md).
