# Contact Deck native review target

Isolated SwiftUI + SwiftData iOS 18+ application. It does not change Spread's Capacitor app, store, bundle identifier, signing, or release workflows. The owner explicitly requested this separate native target in PR #104.

Open the included `ContactDeck.xcodeproj` on macOS with Xcode. `project.yml` is the reproducible XcodeGen source (`cd native/ContactDeck && xcodegen generate`). Scheme: ContactDeck. Simulator signing is disabled. Set the Contact Deck signing team for hardware builds; no team or profile is borrowed from Spread. CI generates the same project, builds, runs persistence/physics and UI tests, and uploads the result bundle and screenshots. No archive, TestFlight upload or deployment occurs.

Native code uses system typography, symbols, controls, semantic colors and materials. Flow is first, Stack peels vertically, Fan pivots from the bottom. Drag prediction settles with a 0.84-damped spring; movement cancels a 460ms hold. The card options menu and accessibility actions provide selection/grouping alternatives. Reduce Motion removes spatial travel and mirrors. SwiftData saves local notes, favorites, decks and soft removal; Recently removed can restore cards after relaunch. The system picker copies only contacts the user selects, without full address-book permission or live writes. Calls/messages hand off; only an explicit “Mark reached out” updates suggestions. Fictional sample numbers never open calling apps.

Complete is a StoreKit nonconsumable, verified from transactions and current entitlements; cancellation, pending and restore are handled. The sample `.storekit` configuration uses **a local testing price only**. Production price/product availability comes exclusively from App Store Connect. No automatic paywall on launch, browsing, mode changes, or notes. The free collection holds 12 cards. The paid style is portrait versus initials, using the same Light/Dark presentation; no themes or design eras.

Verified in macOS CI: the native app builds and runs in an iPhone simulator, all four persistence/physics/model tests pass, and both UI tests pass, including browsing, flip, search, saved notes, deck creation, and the visible onboarding journey under 25 seconds. This is simulator evidence; physical cold-launch latency and competitive enjoyment are unverified.

Release gates remain: physical iPhone/iPad 60fps, haptics, VoiceOver, Dynamic Type and gesture cancellation checks; sandbox purchase/revocation/restore; signed build and real identity; final app icon/store metadata/privacy review. Optional iCloud sync is deliberately unavailable, disabled, and excluded from the unlock promise until entitlements, lossless migration and two-device recovery are verified. No claim of production readiness or parity with Apple Music/Wallet is established by browser tests.
